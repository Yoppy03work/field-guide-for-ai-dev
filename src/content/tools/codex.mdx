## このツールをひとことで言うと

**PR 提出時に自動でレビューコメントを書いてくれる AI**。
型エラー / 命名 / テスト漏れなどのチェックを、人間レビュー前にこなす。

## 開発フローのどこで使うか

- [Step 5: Codex にレビューしてもらう](/workflow#step-5)
- PR テンプレに「Codex への指示」欄を用意すると、的を絞ったレビューが来る

## 実際に試したこと

- PR で型エラー検出、命名提案、テスト追加提案
- このリポジトリの PR テンプレに「TypeScript strict 違反」「@apply 混入」などの観点を明記して運用

## 効果があったこと

- 人間レビュー前のフィルタとして優秀
- 機械的な「@apply 入っちゃった」「any が混じった」などをすぐ見つけてくれる

## 微妙だったこと

- 的外れ指摘もある（「全部対応しなくていい」と割り切る前提）
- 設計レビュー（「このアーキでいいか」）は守備範囲外

## 駆け出しが最初に試すなら

- 自分のリポジトリで PR を1つ出して、Codex のコメントが来るのを待つ
- 1 件だけ取り込んでみる（全部対応しなくていい）
