## やりたかったこと

別の Web アプリのプレビュー URL に対し、画面崩れがないかをブラウザ AI で
巡回確認したかった。

> 🟡 **一部実体験**：先週、別プロジェクトで 1 回試したベース。
> 本サイト（field-guide-for-ai-dev）では未実施です。

## 使った AI / ツール

- Antigravity（ブラウザ操作 AI）
- Vercel Preview（チェック対象の URL 発行元）

## 実際に投げた指示

```
このプレビュー URL を 30 秒見て、レイアウト崩れ / 横スクロール /
ファーストビューで意図した文言が見えているかを報告してください。
スクショは /tmp に保存してください。
```

## 返ってきた結果

- スクショ複数枚 + 「ここで横スクロールが出る」「このボタンが画面外」
  などの気づきリスト
- 人間が気づきにくいモバイル幅の崩れを 1 件発見

## 良かった点

- 人間の目では見落としやすいレイアウト崩れを拾える
- スクショと一緒に「位置と理由」を返してくれる

## 微妙だった点

- 1 回しか使っていないので、安定して効くかは未検証
- 「30 秒見て」のような時間指定や、保存先指示の精度がレビュー品質に直結
- 2 回目以降の同じ URL に対する挙動はわからない

## 駆け出しへのアドバイス

プレビュー URL とセットで使うのが王道。最初は「30 秒見て」「スクショは
このパスに保存して」と具体的に指示する。本サイトでも、今後の PR で
試してみる予定（→ Case 3 を更新します）。
