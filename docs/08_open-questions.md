## Q6. ホームページのトーン

- 「まずはここから」を最も目立たせる
- ツール早見グリッドも置く（旧仕様）

潜在的な競合:
- 「まずはここから」ばかり強調すると、リピーター（既に GitHub に慣れた人）が即離脱
- ツール早見が大きすぎると、新規が「ツール紹介サイト？」と誤解

候補:
- 案A：「まずはここから」を上に大きく、ツール早見はかなり下
- 案B：両方を中段に並列配置（タブ切替）
- 案C：1スクロールに収まるよう全体をコンパクトに

→ **レビュー観点**: ファーストビューで何を見せるか
