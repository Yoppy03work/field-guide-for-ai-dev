## 2. ターゲット

### プライマリ：大学1年生〜駆け出しジュニアエンジニア

- **想定属性**:
  - 情報系の大学1〜2年生
  - 文系学部からプログラミングに挑戦中の学生
  - 新卒〜入社2年目のジュニアエンジニア
- **既存知識**:
  - HTML/CSS/JavaScript は学校で軽く触ったことがある
  - Git / GitHub の **言葉は聞いたことがあるが、使ったことがない**
  - ChatGPT 程度の AI は使ったことがある
  - Claude Code / Codex / Antigravity は **名前すら知らない可能性**
- **困りごと**:
  - GitHub の Issue / Branch / PR / Merge の意味が混ざる
  - AI ツールが多すぎて、何をいつ使うか判断できない
  - チーム開発の現場感がわからない
- **取得したい価値**:
  - 専門用語に「ひとことで言うと」が付いていて、迷子にならない
  - **小さな完成例**を最後まで通せる
  - 自分のリポジトリで明日試せる

### セカンダリ：教育者・先輩エンジニア

- 駆け出しに薦める **「最初の1冊」** として参照したい人
- 自分の現場の AI 導入を検討中で、サンプル事例が欲しい人

## 3. 提供する価値（Value Proposition）

> **「AI ツールの使い方ではなく、AI を開発フローのどこに差し込むかを教える教材。
> GitHub の基本から、Issue→PR→Review→Deploy までを 1 つの例で通す。」**

差別化ポイント：

1. **`/learn/github`** で大学1年生でもわかる用語解説（「ひとことで言うと」付き）
2. **`/workflow`** が中心ページで、AI ツールはその道具として登場
3. **`/cases`** にこのアプリ自身の制作ログを公開（駆け出しが「真似できる」具体例）
4. **🟢🟡🔵 のソース・バッジ** で、各ページが実体験ベースか調査ベースかを明示
5. AI API を使わない静的サイトなので、駆け出しが **clone してそのまま動かせる**

## 5. 機能要件

### F1. ナビゲーション
- Header: `まずはここから` / `ワークフロー` / `ツール` / `Cases` / `About`
- モバイルではハンバーガーメニュー
- 全ページからホームへ戻れる

### F2. ホームページ
- ヒーロー（タイトル/サブタイトル）
- **「まずはここから」** ブロック → `/learn/github` へ誘導
- AI 開発フロー要約 → `/workflow` へ誘導
- 7 ツールの早見グリッド（バッジ付）
- 最新 Cases 3 本のカード
- フッタ（バッジ凡例 / GitHub / About）

### F3. `/learn/github`
- 9 セクションを順に表示（GitHub って何 → リポジトリ → Issue → Branch → PR → Review → Merge → Vercel Preview → AI ツールの差し込みポイント）
- 各セクションに「ひとことで言うと」「具体例」「次へ」リンク
- 最後に **ミニ課題** を 1 つ通す（自己紹介カードの追加など）

### F4. `/workflow`（中心ページ）
- 8 ステップフロー（Issue → Branch → Claude Code → PR → Codex → Antigravity → Vercel Preview → Merge）
- 各ステップ:
  1. 何をするのか
  2. なぜ必要なのか
  3. 初心者がハマりやすいところ
  4. AI ツールをどう使うのか
  5. 自分で試すための小さな課題
- Mermaid 図で全体像を可視化

### F5. `/tools` 一覧 + `/tools/[slug]` 詳細
- 7 ツール（GitHub, Claude Code, Codex, Antigravity, Vercel, Copilot, 他 AI）
- 各ツール詳細:
  1. このツールをひとことで言うと
  2. 開発フローのどこで使うか
  3. 実際に試したこと
  4. 効果があったこと
  5. 微妙だったこと
  6. 駆け出しが最初に試すなら
  7. 関連する Case / Issue / PR

### F6. `/cases` + `/cases/[slug]`
- このアプリ自体を作る過程を教材化
- 各 Case のテンプレ:
  - やりたかったこと
  - 使った AI / ツール
  - 実際に投げた指示
  - 返ってきた結果
  - 良かった点
  - 微妙だった点
  - 駆け出しへのアドバイス
  - 関連 Issue / PR
- 初期投入は Case 1〜4
  - Case 1: Claude Code に UI 実装を任せた
  - Case 2: Codex に PR レビューさせた
  - Case 3: Antigravity に画面確認させた
  - Case 4: Vercel Preview で確認した

### F7. ソース・バッジ表示
- 各ページの先頭に表示
- 🟢🟡🔵 を絵文字 + テキストラベル
- Frontmatter の `status` フィールドから自動描画
