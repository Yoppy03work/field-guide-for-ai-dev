## プロジェクト概要（30秒）

- **何**: 大学1年生〜駆け出しエンジニア向け、**AI 開発フローを真似できる教材アプリ**
- **誰**: 大学1年生〜社会人2年目程度の Web 開発初学者
- **なぜ**: GitHub の基本に不慣れな読者でも、Issue→PR→Review→Merge→Deploy の流れに AI をどう差し込むかを体感できるサイトを作る
- **どこで**: Vercel にデプロイ
- **いつまで**: 1〜2週間（MVP）
- **どうやって**: Claude Code で実装、Codex/Antigravity でレビュー
- **重要な制約**:
  - **AI API は使わない**（純 Static サイト）
  - **AI ツール紹介を主役にしない**（主役は「フロー」、ツールは道具として扱う）
  - **🟢実体験 / 🟡一部 / 🔵調査ベース** をバッジで明示する誠実運用

## レビュアーへの基本方針

1. **甘いレビューは要らない**。「ここは筋が悪い」を具体的に指摘してほしい
2. **大学1年生〜駆け出し視点** で「これは伝わらない／読めない／真似できない」を厳しく判定してほしい
3. **1〜2週間という制約** を踏まえて、**削るべきもの**を率直に提案してほしい
4. **AI API を使わない方針** は固定。「AI で要約機能を入れたら？」のような提案は不要
5. **ツール紹介を主役にしない方針** は固定。「ツールページをもっと派手に」は不要
